Sebelum kita mula

Terminal kursus: Git Bash

Kenapa bukan PowerShell atau CMD?

Slide kursus ini guna arahan seperti curl -H, grep, time dan DB_CONNECTION=mysql php artisan test. Dalam PowerShell atau CMD, arahan ini gagal atau berkelakuan lain.

Dalam Git Bash

Semua arahan berjalan tepat seperti dalam slide. Salin, tampal, jalankan.

  1. Pasang Git for Windows: git-scm.com/download/win. Git Bash disertakan
  2. VS Code: Ctrl+Shift+P → Terminal: Select Default Profile → Git Bash
  3. Buka terminal baru dan semak:

php -v
curl --version
grep --version

Ketiga-tiganya mesti menjawab. Jika php: command not found, tambah folder PHP (Laragon, Herd atau XAMPP) ke PATH Windows dan buka semula terminal.

Peserta guna Windows; kursus diseragamkan pada Git Bash supaya semua arahan dalam slide boleh disalin terus. Git for Windows membawa curl, grep dan time. jq tidak disertakan; ia hanya muncul dalam satu contoh carian log Modul 5 dan tidak wajib. Arahan interaktif seperti php artisan tinker dalam tetingkap Git Bash berasingan (mintty) mungkin perlu winpty php artisan tinker; terminal Git Bash dalam VS Code biasanya tidak perlu. Langkah ini tidak diuji pada mesin Windows semasa penyediaan; cuba pada satu PC makmal sebelum kursus.
Sebelum kita mula

Semak persekitaran anda


php -v            # PHP 8.4
composer -V       # Composer 2.x
git --version
mysql --version   # atau psql --version
redis-cli ping    # PONG (Modul 2 & 4)

git clone <url-starter-repo> laravel-advanced
cd laravel-advanced
composer install
cp .env.example .env && php artisan key:generate
php artisan migrate --seed
php artisan --version  # Laravel Framework 13.x
php artisan test       # semua mesti lulus
